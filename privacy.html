Política de privacidade · Dark Planner

Última atualização: novembro de 2026.

Quem usa

O Dark Planner é uma ferramenta pessoal, usada pelo próprio dono dos canais do YouTube que gerencia.

Quais dados são lidos

Com a autorização do usuário, o app lê, pela API do YouTube Analytics e pela YouTube Reporting API, métricas dos canais autorizados: visualizações, tempo de exibição, retenção, impressões e CTR das miniaturas, inscritos, comentários, curtidas e fontes de tráfego.

O app não lê mensagens, e-mails, dados de pagamento nem informações de outros canais além dos autorizados.

Como os dados são guardados

As métricas ficam em um banco de dados local, no computador do usuário. O token de acesso fica guardado localmente e pode ser revogado a qualquer momento na conta Google (Segurança → Acesso de terceiros).

Compartilhamento

Os dados não são vendidos nem repassados a terceiros. Para gerar análises, trechos das métricas são enviados à API do Google Gemini, usada pelo próprio usuário.

Revogar o acesso

Para remover o acesso do app, use a página de permissões da conta Google ou desconecte o canal dentro do Dark Planner.

Contato

Dúvidas: use o e-mail de suporte informado na tela de consentimento do Google.
